Infrastructure Stack

Clinic Web Suite · Hosting & Upgrade Guide

Prepared by Vimal Raj S & Suruthika R for Dr. Kanak's Clinic

Active Setup: 100% Free

Executive Summary

The clinic's web suite is currently deployed on modern, highly secure, serverless cloud infrastructure configured under permanent free hosting tiers ($0/month). This allows the system to run indefinitely with zero maintenance fees. However, free cloud platforms include resource limits and "autosuspend/sleep" functions when inactive. This document outlines your current free limits, details when you should consider upgrading, and provides cost-effective step-by-step guidance.

Detailed Stack Breakdown

Cloudflare Pages

Frontend UI

Serves the interactive Patient Portal and Admin Board globally via ultra-fast Edge servers.

Free Limits: Unlimited bandwidth, unlimited site visits.
Upgrade trigger: Practically never. The free plan supports millions of monthly visitors.
Upgrade Required: Never

Render API Server

Backend Web Service

Handles appointment bookings, database connections, notifications, and verification logins.

Free Limits: Service spins down (sleeps) after 15 mins of inactive time.
Delay: First visitor after a break waits 50s for wake-up.
Recommended: Starter Tier ($7/mo)

Neon PG Database

Relational Database

Securely holds patient profiles, clinical visits, login keys, and booked slots.

Free Limits: 3 GB storage. Compute autosuspends after 5 mins of inactive time.
Delay: First query after sleep takes 3-5 seconds to load.
Optional: Launch Tier ($19/mo)

When Should You Upgrade?

Phase 1: Initial Growth (0 - 500 Patients)

Stay on the FREE plan. At this stage, the patient flow is sparse. The 50-second wake-up delay on the first API call of the session is easily managed, and 3 GB of database storage is massive (capable of storing 15,000+ patient records).

Phase 2: Active Daily Appointments (500+ Patients)

Upgrade Render API ($7/mo) to eliminate the cold-start delay. This keeps the backend server running 24/7. Visitors booking appointments throughout the day will experience instant page response times instead of occasional delays.

Phase 3: Scale & Backup (Over 3,000 Patients or High Data Volume)

Upgrade Neon Database ($19/mo) if storage approaches 3 GB or you want automated daily backups with point-in-time recovery. It also ensures the database is hot and ready instantly at any millisecond.

How to Upgrade (Step-by-Step)

1 Upgrade Render Backend API

  1. Log into the Render Dashboard (render.com) using the project account.
  2. Select the active **Web Service** representing `drkanaksbackend`.
  3. Go to the **Settings** tab.
  4. Locate **Instance Type** and click **Upgrade/Edit**.
  5. Select the **Starter** instance type ($7 USD / month).
  6. Add billing/payment method details and save changes.

2 Upgrade Neon PostgreSQL Database

  1. Log into the Neon Console (neon.tech).
  2. Open the active database project.
  3. Navigate to the **Plans** or **Billing** tab in the sidebar.
  4. Choose the **Launch Plan** ($19 USD / month) and subscribe.
  5. No code changes or DNS updates are required; the upgrade is applied instantly in-place.
